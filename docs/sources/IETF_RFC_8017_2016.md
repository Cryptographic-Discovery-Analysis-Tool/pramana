# RFC 8017 — PKCS #1: RSA Cryptography Specifications Version 2.2

- **Publisher:** IETF (Internet Engineering Task Force); RFC Editor
- **Authors:** K. Moriarty (Ed., EMC), B. Kaliski (Verisign), J. Jonsson,
  A. Rusch (RSA)
- **Date:** November 2016
- **Category:** Informational
- **DOI:** 10.17487/RFC8017
- **URL:** https://www.rfc-editor.org/rfc/rfc8017.txt (info page: https://www.rfc-editor.org/info/rfc8017/)
- **Retrieved:** 2026-09-28, plain-text/HTML RFC (via web fetch)
- **Why vendored:** a PKCS#12 keystore or X.509 certificate's RSA public key
  is sometimes reported by tooling under its ASN.1 OID name
  (`rsaEncryption`) rather than the plain string `RSA`. This RFC is the
  document that names that OID, so the `rsaEncryption -> RSA` naming-identity
  alias in `data/crypto_families.yaml` has a citable source.

## Appendix A.1 — RSA Key Representation

Exact ASN.1 definition:

- "rsaEncryption OBJECT IDENTIFIER ::= { pkcs-1 1 }"

which is the numeric OID 1.2.840.113549.1.1.1. `pkcs-1` is defined earlier in
the same appendix as the arc `{ iso(1) member-body(2) us(840)
rsadsi(113549) pkcs(1) 1 }`. This is a naming-identity statement (the OID
name for an RSA key), not a security claim -- used the same way
`data/crypto_families.yaml`'s existing `secp256r1 -> P-256` rows are.
